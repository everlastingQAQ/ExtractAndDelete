# Extract & Delete 4.1.0 Developer Preview

这是 Windows 11 x64 Developer Preview 安装器，不是受信任签名的正式生产安装包。

## 安装前提

- Windows 11 x64，build 22000 或更高。
- 必须手动开启“设置 → 系统 → 面向开发人员 → 开发人员模式”。
- 安装器不请求管理员权限，只安装到当前用户。
- 安装器、应用和卸载器未进行 Authenticode 签名，Windows 可能显示 SmartScreen 或“未知发布者”警告。
- 安装器不会自动修改 Developer Mode，也不会导入证书。

## 安装

下载 `ExtractAndDelete-Setup-4.1.0-x64.exe`，先核对同名 `.sha256` 文件，然后双击运行。

安装完成后可以从开始菜单启动 `Extract & Delete`，也可以在 Explorer 中对单个 `.zip`、`.7z`、`.rar` 或 `.tar` 文件使用“解压并回收”。

安装器默认不创建桌面快捷方式，也不会自动更新。后续升级时运行新的安装 EXE 即可。

## 卸载

Windows 可能显示两个入口：

- `Extract & Delete（完整卸载）`：推荐使用，会注销 package 并删除安装器管理的文件。
- `Extract & Delete（系统集成组件）`：只移除 package 注册和 Explorer 集成，文件仍保留；如误用，请重新运行安装器修复后再执行完整卸载。

如果 Shell Extension 正被 Explorer 占用，完整卸载可能要求注销登录后重新运行。

## 安全行为

只有完整解压、无跳过并成功移入回收站时，源压缩包才会被移入回收站。解压失败、取消、发布失败、冲突跳过或回收失败时，源文件保留。

## 完整性

Release 同时提供 SHA-256 文件和 GitHub Actions 构建证明。构建证明用于确认构建来源，不等于 Windows 受信任代码签名。
