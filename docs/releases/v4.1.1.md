# Extract & Delete 4.1.1 Developer Preview

4.1.1 是 4.1.0 的修复版，仍然只支持 Windows 11 x64 和 Developer Mode。它修复了 4.1.0 安装器注册 MSIX 占位符清单导致的开始菜单启动失败、Explorer 右键 RPC 错误和设置页面长时间等待。

下载并运行：

```text
ExtractAndDelete-Setup-4.1.1-x64.exe
```

安装器会为当前用户注册真实的：

```text
Executable = ExtractAndDelete.Gui.exe
EntryPoint = Windows.FullTrustApplication
```

如果检测到 4.1.0 的损坏或残留 package（例如 `InstallLocation` 为空或清单仍包含 `$targetnametoken$`），4.1.1 会在验证新 payload 后精确修复 `ExtractAndDelete`，不会删除仓库目录、用户压缩包或其他应用。

仍然需要：

- Windows 11 x64，build 22000 或更高。
- Developer Mode。
- 允许未签名 Developer Preview 触发 SmartScreen/未知发布者提示。

安装完成后可以从开始菜单启动，也可以在 Explorer 中对 ZIP、7Z、RAR 或 TAR 使用“解压并回收”。成功完成后源压缩包会移入回收站。

4.1.0 的 tag 和 Release 保持不变；新版本不覆盖旧资产。完整卸载请优先使用 `Extract & Delete（完整卸载）`，而不是只移除 `Extract & Delete（系统集成组件）`。
