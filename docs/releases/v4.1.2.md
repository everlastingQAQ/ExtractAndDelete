# Extract & Delete 4.1.2 Developer Preview

4.1.2 是 4.1.1 的轻量化修复版，仍只支持 Windows 11 x64 和 Developer Mode。它保留自包含的 .NET 10、Windows App SDK 2.3.1、7-Zip 26.02 和 Explorer 右键集成，不要求用户安装外部运行时。

## 本版本变化

- 修正 Inno Setup 安装向导的产品名：安装过程中显示 `Extract & Delete`，不再错误显示“完整卸载”。
- 保留“Extract & Delete（完整卸载）”作为系统卸载入口名称，避免用户把安装过程和卸载入口混淆。
- 仅将 `zh-CN` 卫星资源打入自包含 GUI，减少安装包体积；不启用 .NET trimming，不删除 Windows App SDK、7-Zip 或 Shell Extension 运行文件。
- 延续 4.1.1 对 loose-file 清单、开始菜单启动、Explorer 激活和卸载卡顿的修复。

## 下载与安装

下载 `ExtractAndDelete-Setup-4.1.2-x64.exe` 后双击运行。安装器仍然：

- 只支持 Windows 11 x64，并要求手动开启 Developer Mode。
- 仅为当前用户安装到 `%LOCALAPPDATA%\Programs\ExtractAndDelete`。
- 不请求管理员权限、不导入证书、不创建桌面快捷方式。
- 未使用生产 Authenticode 签名，SmartScreen 可能显示未知发布者警告。

安装完成后，从开始菜单启动 `Extract & Delete`，或在 Explorer 中对单个 ZIP、7Z、RAR、TAR 使用“解压并回收”。

## 校验与限制

`.sha256` 文件可选用于验证下载完整性；它不是 Windows 签名，也不会改变 Developer Preview 的信任状态。安装器不包含 CLI、PDB、源码或开发缓存，也不会自动更新。

4.1.1 Release 和 tag 保持不变。若已安装 4.1.0/4.1.1，直接运行 4.1.2 安装器即可安全迁移或修复；仓库目录和用户文件不会被清理。
